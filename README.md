## 📌 Project Overview

This project is an **Excel-based Sales & Profit Dashboard** created to transform raw sales data into meaningful business insights.

The dashboard provides a visual summary of sales and profit performance using **Microsoft Excel**, helping users quickly understand important business metrics and performance trends.
